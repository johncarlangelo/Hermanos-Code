# Upcoming Features

Based on the DevSwarm UI/UX patterns and the product requirements, these features are planned for future implementation:

1. **Dynamic Island HUD**: A floating, draggable "pill" state that stays always-on-top, providing global swarm status when the main command center is minimized.
2. **Multi-Repo Workspace Groups**: Enhanced tree view organization that groups agent sessions by distinct Git repositories, supporting polyrepo workflows in a single UI.
3. **Context & Memory Drawer**: A slide-out side panel for each terminal pane that displays the exact files, context, and prompts currently loaded into the agent's memory.
4. **Jira & GitHub Integration Badges**: Rich metadata indicators on sidebar nodes showing linked tickets, PR statuses, and live git diff statistics (e.g., `+142 -12`).
7. **Cross-Pane Node Graph (HiveControl)**: A visual network graph view showing how different agents are passing messages, reporting progress, and handing results to each other.
